1. 객체지향 개념
	- 자바파일을 만드는 것을 : 자료 설계라 한다. = Test01.java 이 작업을 자료설계라 한다.
	>> 작은 단위 프로그램 = 모듈
		=컴파일하면 Test01.class(레퍼런스 자료형)
		
		Test01 t = new Test01(); //객체생성, 생성자가 호출된다.
		t : 클래스변수(레퍼런스 변수=참조), 인스턴스, 객체
		t.aa(); //객체.메서드();
		
2. 객체지향 4대 특성
	1) 캡슐화 : class Test01{내용} => 묶는 것
	2) 상속 : 자바는 모든 클래스가 상속으로 이루어진다.
			class Test01 extends 상위클래스{}
			class Test01 extends Object {} //오브젝트가 최상위 클래스기 때문에 무조건적으로 상속되어있음
	3) 다형성(Polymorphism) : 오버로드(Overload), 오버라이딩(Overriding)
		- 다형성의 의미는 하나이지만, 실제 형태는 여러 가지가 될 수 있다는 뜻이다.
		
		//예시 (점심을 먹다라는 의미가 하나이지만 실제로 무엇을 먹었는지가 다름)
		점심을 먹다(){한식을 먹음}
		점심을 먹다(){전북죽을 먹음}
		점심을 먹다(){라면을 먹음}
		
		■ 오버로드 : 하나의 클래스안에 이름이 같은 메서드가 여러개 있는 경우
			- 구분은 매개변수의 개수나 자료형이 달라야한다.
			- 리턴형은 상관없음
			
		■ 오버라이딩 : 상속 받은 메서드 내용을 재정의 하는 것
			- 리턴형, 메서드 이름과 매개변수가 반든시 같아야 한다.
			- 
		
		접근제한자
		private : 자신의 클래스 안에서만 접근 가능
		생략 : 같은 패키지에서 접근 가능하다
		protected : 패키지가 다르더라도 상속 받으면 접근 가능하다.
		public: 패키지가 다르더라도 어디서나 접근 가능하다.
		
	4) 추상화 : 복잡한 것을 단순화 하는 것
		- 복잡한 것? = 클래스 설계자 입장
