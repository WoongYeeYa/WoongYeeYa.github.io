생성자

	1. 생성자는 클래스 이름과 같다.
	2. 생성자는 리턴형이 없다. 필드(객체)초기화가 목적이다.
	3. 매개변수를 갖는다.(매개변수=인수=인자) >> 오버로드가 가능하다.
	4. 객체생성 시 호출된다.
	
	5. 생성자를 넣어주지 않으면 디폴트 생성자가 자동으로 만들어 진다.
		- 디폴트 생성자 : new Test01()
	6. 매개변수가 있는 생성자를 넣어주면, 디폴트 생성자는 만들어지지않는다.
		- 프로그래머가 디폴트 생성자를 넣어줘야한다.
		


	7.this : 현재 클래스 객체, 많이 사용 (this.전역변수=매개변수;)
	  this() : 자신의 클래스안의 생성자 호출, 거의 사용 하지 않음
	  this(매개변수) : 
	  ■ this()는 생성자 안에서 첫 줄에 기재해야한다.
	8. super : 상위 클래스 개체 (사용 하지말아야 할 것)
	   super() : 상위 클래스 생성자 호출 (많이 사용)
	  ■ super()는 생성자 안에서 첫 줄에 기재해야한다.
	  
	  ※this()와 super()는 둘 다 첫 줄에 기재해야하기 때문에 동시 사용이 불가하다.
