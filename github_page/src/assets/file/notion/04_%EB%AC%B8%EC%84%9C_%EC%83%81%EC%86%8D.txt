04_문서_상속

클래스 상속
이미 만들어진  클래스를 상속받아서 또 다른 클래스를 만들 수 있다.

예:
class 파생클래스 extends 수퍼클래스{
	변수, 생성자, 메서드
}

class 파생클래스 implements 인터페이스{

}

class 파생클래스 extends 수퍼클래스 implements 인터페이스, 인터페이스{

}

//같은 급끼리 상속을 받을 때는 extends
클래스가 클래스를 상속받을 때는 extends
클래스가 인터페이스를 상속받을 때는 implements
인터페이서가 인터페이스를 상속받을 때는 extends
