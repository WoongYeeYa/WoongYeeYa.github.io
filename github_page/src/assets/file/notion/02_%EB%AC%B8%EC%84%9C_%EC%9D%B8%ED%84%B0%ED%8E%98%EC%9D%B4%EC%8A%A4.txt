추상클래스
1. 추상클래스는 내용 있는 메서드와 추상메서드가 혼합되어 있는ㅇ 것이다.
   cf: 일반 클래스는 내용 있는 메서드만 있는 것
      인터페이스는 추상메서드만 있는 것
      추상클래스는 내용 있는 메서드와 추상메서드가 함께 있는것

2. 클래스 extends 추상클래스{
	추상메서드 오버라이딩
	}
=======================================================
		interface					abstract class
-------------------------------------------------------
키워드	interface					abstract class
메서드	모두 추상메서드					일반메서드, 추상메서드
다중상속	가능							불가능
변수		static final 변수				프로그래머 마음대로 사용가능
=======================================================

	※static final 변수 : 값 변경 못함(변수를 상수화 하는 것)
	 final 메서드 : 재정의 불가능(오버라이딩)
	 final 클래스 : 상속 불가능
	 
	 추상 클래스는 객체생성을 할 수 없다.
