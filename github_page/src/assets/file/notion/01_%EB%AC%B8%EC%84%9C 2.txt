01_문서

	배열 (Array)

	- 동질 자료형의 기억장소 집합체이다.
	
	- 예를 들어 (변수 : 단독주택)
	
		int a = 10;
		int b = 20;
		int c = 30;
	
	- 배열 예제 (배열 : 아파트)

		int a[] = new int[3];
		a[0]=10;
		a[1]=20;
		a[2]=30;
	
		int a[]={10,20,30};
	
	열의 장점 : 자료를 일괄 처리할 수 있다.
	배열은 new 연산자를 사용해서 생성한다. heap영역에 메모리 할당된다.
	new : heap 영역에 클래스 객체를 생성하는 연산자이다.
	자바에서는 배열도 class의 일종이다.
	
	1) 형식
	자료형 [] 배열명=new 자료형[요소갯수]; // 배열선언, 배열생성
	예:
	int a[] = new int[3]; //배열 선언, 배열생성
	
	2) 형식
	자료형 []배열명 =new 자료형[요소갯수]; //배열선언, 배열생성
	
	3) 형식
	자료형 []배열명={초깃값,초깃값,초깃값....}; //배열선언, 배열생성, 초깃값 넣기
	
	예:
	int a[]={10,20,30};
