변수
	- 기억장소 이름을 지칭하는 것
	
	-------------------------------
	자료형    변수이름  = 값;
	int   kor   = 99;
	-------------------------------
	
	식별자(명칭 = identifier) : 변수이름, 메서드 이름, 클래스 이름
	
	식별자 사용규칙
		1. 영문자로 시작해야 한다.(ex : int a = 100, String name = "ㅇㅇㅇ")
		2. 영문자, 숫자를 조합해엇 사용이 가능하다. (ex : int a1 =100)
		3. 명칭은 공백을 사용 못한다. (ex : int a 1=100 << 이와 같이 a 1 사이에 공백이 있으면 사용불가)
		4. 예약어(키워드)는 명칭으로 사용할 수 없다. (class, int, double, public, static)
		5. 특수문자 사용 불가 (단 _,$는 사용가능)
			int _a=100; //옳은 예제
			int $a=100; //옳은 예제
			int #a=100; //틀린 예제
			_는 많이 사용하지만 $는 많이 사용하진 않음
		

	자동형변환
		- 할당 시(대입할 때) : 왼쪽이 오른쪽 자료형 보다 클 때 자동으로 형 변환이 된다.
		- ex : double a = 100; //대입 되면서 double 형으로 변환된다.
			   (double은 실수형 100은 정수기 때문에 실수에 포함되므로 자동으로 형 변환)
		- 연산할 때는 자료형이 큰쪽으로 변환
		
	강제형변환=캐스팅=casting
		- ex : int a = 12.5; //왼쪽 자료형이 작을 때는 에러 발생
		- int b = (int)12.5; //
		- char ch=(char)65;
		- char ch2(char)65.5;
		
	변수를 상수화 시키는 것
		값 변경 불가
		- final int MAX = 100;
		- MAX = 500; //에러
