예외(Exception)이란?
프로그램을 실행 하는 동안 예기치 않은 상태(예외 상황)이 발생하는 것을 말한다.

에러란? : 프로그램 문법적인 오류이다.

예외도 에러이다.

Exception은 사전에 프로그래머가 예상해서 처리할 수 있는 가벼운 에러로 예외 종류는 클래스 계층구조로 되어있다.
  
  
  Object
    ↓
  Throwable
    ↓
  Exception
  
  ■ 컴파일 에러 : 고칠 수 없는 에러
	IOException
	FileNotFoundException
	ClassNotFoundException (DB에서 필수로 사용)
  ■ 런타입 Exception : 고칠 수 있는 에러
	ArrayIndexOutOfBoundsException
	NumberFormatException : 숫자를 잘못 입력했을 때 발생
	ArithmeticException : 연산을 잘못 했을 때 발생 (값/0)
	

  ■ 예외처리 방법 2가지
  	방법 1 : 직접 처리
  	try{
  		처리내용;
  		처리내용;
  		}catch(예외종류1){메시지 출력;}
  		 catch(예외종류2){메시지 출력;}
   		 catch(예외종류3){메시지 출력;}
		finally{
				//finally 절은 예외 발생과 상관없이 처리된다.
				//심지어 앞에 return문이 있어도 finally 절은 처리된다.
				//그러나 앞에 System.exit(0)문이 있으면 finally 절을 처리하지 않는다.
				
				//IO
				//DB
				rs.close();
				stmt.close();
				con.close();
		}
