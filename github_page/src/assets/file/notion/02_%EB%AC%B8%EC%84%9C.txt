	대입 연산자
	: 연산을 먼저 진행하고 변수에 해당값을 할당
	================================================
	연산자 종류			사용예시			의미
	------------------------------------------------
	=				a=2				a=2				ㅣ
	+=				a+=2			a=a+2			ㅣ
	-=				a-=2			a=a-2			ㅣ
	*=				a*=2			a=a*2			ㅣ		
	/=				a/=2			a=a/2			ㅣ
	%=				a%=2			a=a%2			ㅣ	
	------------------------------------------------
	<<=				a<<=2			a=a<<2			ㅣ
	>>=				a>>=2			a=a>>2			ㅣ
	------------------------------------------------
	&=				a&=2			a=a&2			ㅣ
	|=				a|=2			a=a|2			ㅣ
	^=				a^=2			a\a^2			ㅣ
