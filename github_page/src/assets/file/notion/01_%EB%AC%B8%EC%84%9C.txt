연산자(operation)의 종류
	1. 산술 연산자
		
		■ 덧셈(+),뺄셈(-),곱하기(*),나누기(/),나머지(%)
		■ ++ : 1씩 증가하는 연산자
		■ -- : 1씩 감소하는 연산자
		
		정수/정수 : 몫
		정수/실수 : 실수값 발생(자동형 변환 발생)
		
		예: 게시판 게시글의 개수가 37개 있다, 1페이지에 10개씩 출력해라
		   37/10 = 몫 3 (이 식만 있으면 나머지 7개가 사라짐)
		   37%10 = 나머지 7 (이 식을 추가함으로써 총 페이지 수 3+1로 4페이지가 됨)
		
		증감 연산자, 단항 연산자
		■ ++ : 1씩 증가하는 연산자
		■ -- : 1씩 감소하는 연산자
		
		++a; <<< 전위연산
		a++; <<< 후위연산
		++;  <<< 단독으로 사용시 1증가만함 (근데 단독으로 어떻게 사용)
		
		※ 복합연산을 할때는 전위연산, 후위연산이 의미가 있다.
		
		예:
		int a = 5;
		int b = ++a + a++; //복합연산
		계산 순서 ③  ①	②  ④
		
	2. 관계 연산자
	
		■ >	   : 보다 크다
		■ >=   : 크거나 같다
		■ <	   : 보다 작다
		■ <=   : 작거나 같다
		■ ==   : 같다  (할당 연산 >> a=10)
		■ !=   : 같지 않다
		
		  a>b  : a가 b보다 크다
		  a>=b : a가 b보다 크거나 같다
		  a<b  : a가 b보다 작다
		  a<=b : a가 b보다 작거나 같다
		  a==b : a와 b가 같다
		  a!=b : a와 b가 같지 않다.	
		
	3. 논리 연산자
		
		- 일반 논리 연산자
		■ && (and)
		■ || (or)
		■ !  (not)
		
		a&&b
		a||b
		!a
		
		- bit 논리 연산자
		■ & (and)
		■ | (or)
		■ ~ (not)
		■ ^ (xor) = 배타적 or	
		
	4. shift연산자(bit연산=이진 연산)
	
		<< 	: 좌 shift (1bit씩 왼쪽으로 이동, 오른쪽은 0으로 채운다 (X*2ⁿ)
		>> 	: 우 shift (1bit씩 오른쪽으로 이동, 왼쪽은 signbit로 채운다 (X*2ⁿ)
		>>> : 1비트씩 오른쪽으로 이동, 왼쪽은 0으로 채운다 (X/4ⁿ)
