■ String 클래스

	1. substring(int beginindex) : 현재 문자열 객체에서 beginindex 위치부터 끝까지 문자열 발췌
	==========================================================================
	예시
	String str="Good Afternoon gil-dong";
			  //01234567890123456790123 << (beginindex)
	
	String s1=str.substring(16);
	==========================================================================
	
	
	2. substring(int beginindex, int edindex) : 현재 문자열 객체에서 beginindex 위치부터 endindex의 직전까지 문자열 발췌
	=================================================================================================
	예시
	String str="Good Afternoon gil-dong";
			  //01234567890123456790123 << (beginindex)
	
	String str2=str.substring(5,10);
	-------------------------------------------------------------------------------------------------
	응용
	
	주민번호에서 남자인지 여자인지 판별하기
	
		981101-1000000
		01234567890123
	String jumin = "981101-1000000";
	
	String j=jumin.substring(7,8);

	=================================================================================================
