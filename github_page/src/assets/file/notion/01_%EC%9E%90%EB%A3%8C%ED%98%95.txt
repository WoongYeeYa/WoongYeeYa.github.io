ch02-자료형
자료형(data type)
변수(변수명) : 메모리 공간 할당을 받은 후 이름(명칭)
상수 : 값 = 데이터
int    a  = 100
자료형    변수        상수

========================================
자료형의 종류
	1. 논리 자료형
	2. 정수 자료형
	3. 문자형
	4. 실수 자료형
	5. 무치형
	6. 레퍼런스 자료형(참조 자료형)	
========================================
	1. 논리 자료형
		boolean : 1bit로 표현(true/false)
		
	2. 정수 자료형
		byte : 1byte, 숫자(-128 ~ +127), 1문자 표기(A~Z 아스키 문자,아스키 코드)
		char : 2byte 유니코드 문자(한글,일어 etc..) = 코드기 때문에 정수 자료형임
		short : 2byte(-32768 ~ +32767)
		int : 4byte(-2147483648 ~ +2147483647) <<< 기본값
		long : 8byte(-9223372036854775808 ~ 9223372036854775807)
		
	3. 문자형
		char : 2byte 유니코드 (ex: 'A','B'...)
		
	4. 실수 자료형
		float : 4byte(정밀도가 낮음) (정수부, 지수부)
		double : 8byte(정밀도가 높음) (정수부, 지수부) <<< 기본값
		
	5. 무치형
		void(자료형이 없는 것)(매서드 리턴형 : void main)
		
	6. 레퍼런스 자료형(참조 자료형) : heap 영역에 메모리를 할당 = 동적 메모리
		클래스 : System, String, Scanner.....
