# Java 강의 노트 정리

노션 CSV의 강의명과 ‘노트 메모’를 중심으로 연결되는 주제를 다섯 회차에 묶는다. 게시글 데이터는 `src/data/javaStudies.js`에 둔다.

| 회차 | 합친 강의 | 주제 |
| --- | --- | --- |
| 1 | 1~5 | 기초, 자료형, 연산자, 제어문, 배열 |
| 2 | 6~9, DAO 자료 | 메서드, 생성자, 상속, 인터페이스, 추상 클래스, DAO |
| 3 | AWT, 레이아웃, 이벤트, Swing | 화면 구성과 사용자 입력 처리 |
| 4 | 13~16 | 예외, IO, util, 컬렉션과 제너릭 |
| 5 | 17, Network·Network2 | 스레드, 동기화, 소켓 네트워크 |

- 자료는 `src/assets/file/notion`에 보관한다. CSV의 `%25` 이스케이프를 해제하면 첨부파일 이름과 연결된다.
- TXT와 Java 자료에는 CP949와 UTF-8이 섞여 있어 인코딩을 구분해 읽는다. 원본은 변경하지 않는다.
- RTF는 RichTextBox로 읽을 수 있고, `01_Java교안.rtf`는 확장자와 달리 OLE 문서여서 텍스트 추출로 기초 내용을 확인했다.
- ZIP은 실행하지 않고 Java 예제 목록과 필요한 소스를 참고한다. 전체 소스 ZIP과 개별 챕터 ZIP은 중복된 카드로 만들지 않는다.
- `04_UML차트.rtf`의 텍스트는 Servlet 메모이므로 이름만으로 UML 자료라고 분류하지 않는다. 웹 환경·Servlet·DB 메모는 객체지향 회차의 연결 설명에 포함한다.
- 자료형 크기, Set의 중복 규칙, checked 예외와 인터페이스 메서드 등 원본 메모의 부정확한 표현은 정확한 개념으로 정리한다. 게시글에 원본에 대한 피드백을 넣지 않는다.
- 강의명에 Spring·React가 들어 있어도 실제 제공된 메모에 없는 강의 내용을 만들어 넣지 않는다.
- 다섯 글은 `explanationOnly: true`로 공부 흐름과 메모를 표시한다. 경험이나 성과를 만들어 회고 항목을 채우지 않는다.
- Java 글의 외부 참고 자료는 표시하지 않는다. `downloads`로 각 회차의 원본 ZIP을 제공하고, ZIP은 수정·재압축하지 않는다. 전체 `src.zip`은 객체지향 회차에 함께 둔다.
